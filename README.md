# Sodium Dynamic Lights

This is a fork of Sodium Dynamic Lights maintained by KaenguruuDev.

## Compatibility

This NeoForge 1.21.1 build targets Sodium 0.8.13-beta.2 or newer. Its Dynamic
Lights settings are registered through Sodium's Config API and are available
from the Graphics Settings screen.

## Attribution
